The Iris dataset is a famous dataset in machine learning and statistics. It is often used for classification tasks and is included in scikit-learn.

📌 About the Iris Dataset
It contains 150 samples of iris flowers.

Each sample has four features (measurements of flowers):

Sepal length (cm)

Sepal width (cm)

Petal length (cm)

Petal width (cm)

The target variable represents the species of the flower:

0 → Iris Setosa

1 → Iris Versicolor

2 → Iris Virginica

📊 Why is it used?
It is small and easy to understand.

It is a great test case for machine learning algorithms.

It is widely used for classification problems.
